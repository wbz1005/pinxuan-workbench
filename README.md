# 我的品宣工作台 V1.1

记录创意 · 管理项目 · 沉淀成果。一个适合品宣设计、内容运营和视频剪辑的个人创意工作桌面。无账号、无服务器、无外部依赖；工作记录保存在当前浏览器的 `localStorage`。

## 功能

- 今日工作：首页自动展示焦点任务、真实工作数据与最近成果墙；无演示数据。
- 任务看板：新建、编辑、删除任务，按待开始 / 进行中 / 已完成管理；支持项目、优先级、日期、预计工时、安排人、成果链接、修改记录、审核反馈。
- 项目管理：预置五个项目，也可新增项目。只有没有关联任务和证据时才能删除项目。
- 日历排期：查看开始日期和截止日期，点击任务即可编辑。
- 工时：任务卡一键开始、暂停计时；可按日期手动补录，单独标注临时插单或返工。按日、周、项目和工作类型汇总。
- 周报：根据真实完成任务、工时和证据自动生成；支持编辑补充说明、复制、打印和导出 TXT。
- 作品成果与绩效证据：从已完成任务、绩效证据自动汇集作品墙；关联任务与项目，记录完成时间、输出成果、图片或交付链接及备注；证据按月查看。视频记录和内容选题是相应类型任务的快捷入口。
- 数据：下载 JSON 完整备份，并在其他浏览器或设备上恢复。

## 打开网站

如果 GitHub Pages 已启用，访问：<https://wbz1005.github.io/pinxuan-workbench/>。

本地运行需要 Node.js 18 或更新版本。下载或克隆本仓库后，在项目目录运行：

```bash
node server.mjs
```

然后打开 <http://127.0.0.1:4173>。网页使用浏览器模块，直接双击 `index.html` 可能被浏览器安全策略限制，请通过上述地址访问。

## GitHub Pages 设置

本仓库的 `.github/workflows/pages.yml` 会在推送到 `main` 后自动发布 `dist/`。首次部署时，在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。随后可在 **Actions** 页查看发布状态。

## 数据说明

数据只存于当前浏览器及域名下。V1.1 沿用 V1.0 的存储键和备份格式，原有记录不会因升级而重置。清理网站数据、换浏览器或切换部署域名不会自动迁移记录。迁移前在“数据备份”下载 JSON，在新地址恢复。计时器在页面关闭时保留开始时间，重新打开后可继续暂停结算。图片使用链接记录，V1.1 不上传图片文件。
