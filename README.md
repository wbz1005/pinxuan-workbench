# 我的品宣工作台 V1.3

记录创意 · 管理项目 · 沉淀成果。一个适合品宣设计、内容运营和视频剪辑的个人创意工作桌面。V1.3 在 V1.2 雾白灰、墨灰与少量琥珀橙的视觉基础上，增加项目与职业成果管理。无账号、无服务器、无外部依赖；工作记录保存在当前浏览器的 `localStorage`。

## 功能

- 今日工作：首页自动展示焦点任务、真实工作数据、本月分类成果数量与临时需求比例；无演示任务。
- 任务看板：新建、编辑、删除任务，按待开始 / 进行中 / 已完成管理；新增设计、视频、内容、拍摄、沟通、物料六种类型及自主规划、领导安排、临时需求、客户需求四种来源。保留项目、优先级、日期、预计工时、安排人、成果链接、修改记录、审核反馈。
- 项目中心：预置五个可编辑项目，也可新增；记录负责人、状态、起止日期和说明。卡片与详情自动汇总进度、任务和成果。只有没有关联任务、作品或成果档案时才能删除项目。原排期日历从项目中心进入。
- 我的作品库：新增、编辑、删除作品档案；记录项目、关联任务、类型、日期、描述、标签、封面图片、链接和备注。已完成任务及成果档案也自动出现在作品库。
- 成果档案：按月记录完成内容、产生价值、附件图片、成果链接及备注，可关联任务和项目。
- 工时：任务卡一键开始、暂停计时；可按日期手动补录，单独标注临时插单或返工。按日、周、项目和工作类型汇总。
- 周报：根据真实完成任务、工时、作品和成果档案自动生成；支持编辑补充说明、复制、打印和导出 TXT。附有三个本地写作草稿功能，分别生成周报、成果价值描述和作品介绍；它们是可编辑的模板，不是联网 AI。
- 数据：下载 JSON 完整备份，并在其他浏览器或设备上恢复。

## 打开网站

如果 GitHub Pages 已启用，访问：<https://wbz1005.github.io/pinxuan-workbench/>。

本地运行需要 Node.js 18 或更新版本。下载或克隆本仓库后，在项目目录运行：

```bash
node server.mjs
```

然后打开 <http://127.0.0.1:4173>。网页使用浏览器模块，直接双击 `index.html` 可能被浏览器安全策略限制，请通过上述地址访问。

## GitHub Pages 设置

本仓库的 `.github/workflows/pages.yml` 会在推送到 `main` 后自动发布 `dist/`。首次部署时，在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。随后可在 **Actions** 页查看发布状态。

## 数据说明

数据只存于当前浏览器及域名下。V1.3 沿用 V1.0 的存储键和备份格式，旧备份没有作品字段时仍能恢复，原有记录不会因升级而重置。清理网站数据、换浏览器或切换部署域名不会自动迁移记录。迁移前在“数据备份”下载 JSON，在新地址恢复。计时器在页面关闭时保留开始时间，重新打开后可继续暂停结算。上传的图片会被压缩成 JPEG 保存到浏览器，并包含在 JSON 备份内。浏览器本地存储容量有限，请定期备份并控制图片数量。
